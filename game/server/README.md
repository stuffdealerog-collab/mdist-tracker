# Сервер Keyboard Seller Simulator

Отвечает за онлайн-часть игры: коробки с онлайн-предметами, барахолку (обмен между игроками), таблицу лидеров и недельный конкурс.
Без зависимостей: нужен только Node.js 22 или новее (встроенный `node:sqlite`).

## Быстрый запуск
```
node server.mjs            # порт 8787, база kss.db рядом
PORT=9000 DB=/data/kss.db node server.mjs
node test.mjs              # автотест: два игрока открывают коробки и меняются
```
Проверка: `curl http://localhost:8787/health`

## Установка на VPS (Ubuntu)
1. Установите Node.js 22: `curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - && sudo apt install -y nodejs`
2. Скопируйте папку в `/opt/kss`, создайте пользователя: `sudo useradd -r kss && sudo chown -R kss /opt/kss`
3. Сервис: `sudo cp kss.service /etc/systemd/system/ && sudo systemctl enable --now kss`
4. HTTPS: установите Caddy (`sudo apt install caddy`), впишите свой домен в `Caddyfile`, скопируйте его в `/etc/caddy/Caddyfile`, затем `sudo systemctl reload caddy`.
5. Положите рядом с `KeyboardSellerSimulator.exe` файл `server.txt` с одной строкой, например `https://kss.example.com`. Игра подключится сама. Пересобирать игру не нужно.

## API
| Метод | Путь | Что делает |
|---|---|---|
| POST | /auth | вход по device id, выдаёт токен |
| POST | /boxes/open | серверный бросок коробки, предмет получает uid |
| GET | /market | открытые предложения других игроков и ваши |
| POST | /market | выставить онлайн-предмет на обмен |
| POST | /market/:id/accept | принять обмен (атомарно) |
| DELETE | /market/:id | снять своё предложение |
| GET | /inbox | предметы, пришедшие от других игроков |
| POST | /items/:uid/consume | предмет ушёл в проданную клавиатуру |
| POST | /score, /contest | рейтинг и недельный конкурс |
| GET | /leaderboard, /health | таблица лидеров, проверка |

Защита: лимит запросов по IP, не больше одного открытия коробки в 1,5 с и 300 в день на игрока, не больше 10 активных предложений.
Предложения старше 7 дней закрываются, предметы возвращаются владельцам.

Деньги в игре хранятся у игрока локально, поэтому сервер не может проверить, что коробка была оплачена. Он гарантирует другое: что предмет на обмене существует, у него один владелец и его нельзя продать дважды.
Если понадобится защита экономики, следующий шаг — серверный кошелёк, то есть сервер начисляет и списывает монеты сам.
