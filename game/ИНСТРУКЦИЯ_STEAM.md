# Keyboard Seller Simulator — выпуск в Steam

## Что в комплекте
| Файл | Что это |
|---|---|
| `KeyboardSellerSimulator-Windows.7z` | Готовая игра для Windows: один EXE, всё упаковано внутрь |
| `KeyboardSellerSimulator-Linux.7z` | Сборка для Linux / Steam Deck |
| `KSS-server.zip` | Онлайн-сервер: барахолка, коробки, рейтинг (Node.js 22) |
| `KSS-godot-project.zip` | Исходники проекта Godot 4.4 для доработки и пересборки |
| `KSS-steam-assets.zip` | Капсулы и скриншоты для страницы Steam в нужных размерах |

## 1. Проверьте игру
Распакуйте архив (Windows 11 открывает .7z сам, иначе 7-Zip) и запустите `KeyboardSellerSimulator.exe`. Нужна видеокарта с поддержкой Vulkan; подходит любая из последних 8 лет.
Без сервера игра работает полностью: обмен идёт с торговцами города, коробки открываются локально.
Сохранение лежит в `%APPDATA%\Godot\app_userdata\Keyboard Seller Simulator\save.json`.

## 2. Онлайн
1. Арендуйте VPS (Ubuntu, 1 ГБ RAM хватит на тысячи игроков) и домен.
2. Разверните сервер по `KSS-server.zip/README.md`. Это около 10 минут, нужен Node.js 22 и Caddy для HTTPS.
3. Положите рядом с EXE файл `server.txt` с адресом сервера, например `https://kss.example.com`.
   Игроки также могут вписать адрес вручную: «Настройки → Онлайн».
4. Steam: файл `server.txt` кладётся в depot рядом с EXE.

## 3. Steamworks
1. Зарегистрируйтесь в Steamworks (partner.steamgames.com) и оплатите Steam Direct ($100 за игру). Получите **App ID**.
2. Заполните страницу магазина: описание, теги «Симулятор», «Казуальная», «Строительство», «Экономика», минимум 5 скриншотов 1920×1080 и капсулы (готовые лежат в `steam_assets/`).
3. Сборка: **App Admin → SteamPipe → Depots**. Создайте depot для Windows (и отдельный для Linux, если нужен Steam Deck).
4. Загрузите сборку одним из двух способов:
   - **SteamPipe GUI** (Windows): укажите App ID и Depot ID, выберите папку с EXE, нажмите Upload;
   - **steamcmd**: `steamcmd +login <логин> +run_app_build app_build.vdf +quit` (шаблон ниже).
5. **Installation → General**: Launch Option → Executable `KeyboardSellerSimulator.exe`.
6. Выставите билд на ветку default и отправьте страницу и билд на проверку Valve (обычно 3–5 рабочих дней).

```
"AppBuild"
{
  "AppID" "ВАШ_APP_ID"
  "Desc" "v1.0"
  "ContentRoot" "./content/"
  "BuildOutput" "./output/"
  "Depots"
  {
    "ВАШ_DEPOT_ID"
    {
      "FileMapping" { "LocalPath" "*" "DepotPath" "." "recursive" "1" }
    }
  }
}
```

## 4. Достижения Steam
В игре уже есть 28 достижений. Код `SteamBridge` (`autoload/steam.gd`) вызывает `setAchievement("ACH_...")`, как только подключён GodotSteam.
1. В Steamworks: **Stats & Achievements → Achievements**. Создайте достижения с API-именами из таблицы ниже и опубликуйте.
2. Откройте проект в Godot 4.4, затем **AssetLib → GodotSteam GDExtension (4.4)** → установить.
3. Пересоберите: **Проект → Экспорт → Windows Desktop**. Рядом с EXE окажется `steam_api64.dll`.
4. Для локального теста положите рядом с EXE `steam_appid.txt` с вашим App ID; в депо его не кладите.
Без GodotSteam игра работает как обычно, просто без достижений Steam. Внутриигровые достижения работают всегда.

## 5. Пересборка из исходников
1. Godot 4.4.1 (стандартный, не .NET) и шаблоны экспорта 4.4.1.
2. Откройте `project.godot` и выберите **Проект → Экспорт → Windows Desktop → Экспорт проекта**.
3. Иконка EXE уже вшита в шаблон `build/template/windows_release_x86_64_kss.exe`.
   Чтобы заменить иконку, поменяйте `icon.ico` и включите «Modify Resources» (нужен rcedit) или пропатчите шаблон заново.

## Что внутри игры
- **3D-мастерская** с пятью помещениями (гараж → лофт → студия → бутик → флагман): свет, отражения, объёмный туман, глобальное освещение.
- **Ручная сборка в 9 этапов**: детали в корпус, стабилизаторы, смазка (мини-игра), свитчи, пайка, винты с моментом затяжки, кейкапы по рядам, тест клавиш, тест звука.
- **Настоящие записи свитчей** (13 наборов). Звук зависит от корпуса, пластины, кейкапов и модов.
- **Карта города**: поставщики со скидками, клиенты по районам, курьер, покупка помещений.
- **Склад** с 3D-просмотром каждой клавиатуры, **витрина** с офлайн-продажами, **заказы** клиентов и VIP-сюжеты.
- **Коробки** за игровую валюту с открытыми шансами и рулеткой. Эксклюзивные свитчи и кейкапы.
- **Барахолка**: обмен онлайн-предметами с живыми игроками через сервер и с торговцами города.
- **Удержание**: награды за вход, задания дня и недели, group buy, недельный конкурс, рейтинг, филиалы в других городах, 28 достижений.

## 6. Тексты для страницы магазина

**Название:** Keyboard Seller Simulator

**Краткое описание (RU, до 300 символов):**
Откройте мастерскую кастомных механических клавиатур. Собирайте их своими руками: плата, стабилизаторы, смазка, свитчи, винты, кейкапы. Слушайте настоящие записи свитчей, выполняйте заказы клиентов, покупайте помещения и меняйтесь деталями с другими мастерами.

**Short description (EN):**
Run your own custom mechanical keyboard workshop. Build every board by hand — PCB, stabilizers, lube, switches, screws and keycaps — hear real switch recordings, fulfil client orders, buy new shops across the city and trade rare parts with other players.

**Описание (RU):**
Вы начинаете в гараже на окраине с коробкой деталей и одним соседом-клиентом. Каждая клавиатура собирается руками, этап за этапом: вставьте плату и пластину в корпус, поставьте стабилизаторы, смажьте свитчи кисточкой, аккуратно вставьте 104 свитча и не погните ножки, затяните винты крест-накрест с правильным усилием, наденьте кейкапы на свои ряды и проверьте каждую клавишу.

Звук складывается из деталей. Настоящие записи свитчей обрабатываются под ваш корпус, пластину, кейкапы и моды. Глубокий thock, звонкий clack или почти бесшумный офис: решаете вы.

• 29 свитчей, 27 наборов кейкапов, 8 корпусов, 6 пластин, моды и артизаны ручной работы
• 5 раскладок: от компактной 60% до полноразмерной
• Карта города: поставщики со скидками, клиенты по районам, курьерская доставка
• 5 помещений, от гаража до флагмана на набережной. Каждое выглядит по-своему и приводит больше покупателей
• Заказы с ТЗ, VIP-клиенты с сюжетами, витрина, которая торгует, пока вас нет
• Коробки с деталями за игровую валюту с открытыми шансами. Эксклюзивные свитчи и кейкапы
• Барахолка: обмен редкими деталями с другими игроками
• Ежедневные награды, недельные конкурсы, рейтинг мастерских, филиалы в 6 городах, 28 достижений

**Жанры / теги:** Simulation, Casual, Indie, Building, Economy, Crafting, Relaxing, Management, 3D.

**Важно для модерации Valve:** коробки покупаются только за игровую валюту и не продаются за реальные деньги, шансы показаны в игре. В анкете контента отметьте «Внутриигровые покупки: нет».

**Системные требования (минимальные):** Windows 10 64-bit, 4 ГБ RAM, видеокарта с Vulkan 1.1 (GTX 750 / Radeon R7 260 / Intel UHD 620 на низких настройках), 300 МБ на диске.
**Рекомендуемые:** 8 ГБ RAM, GTX 1060 / RX 580 или лучше.
