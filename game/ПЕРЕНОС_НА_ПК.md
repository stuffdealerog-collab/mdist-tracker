# Как продолжить работу на своём ПК

## 1. Установите инструменты
1. **Godot 4.4.1 (Standard, не .NET):** https://godotengine.org/download/archive/4.4.1-stable/
   Распакуйте архив, Godot работает без установки.
2. **Шаблоны экспорта 4.4.1.** В Godot откройте **Editor → Manage Export Templates → Download and Install**.
3. **Node.js 22+** нужен только для онлайн-сервера: https://nodejs.org
4. **Git** (по желанию, для истории изменений): https://git-scm.com

## 2. Получите проект
**Вариант А: архив.** Распакуйте `KSS-godot-project.zip`, внутри будет папка `game/`.

**Вариант Б: git с историей.** Склонируйте из файла-бандла:
```
git clone keyboard-seller-simulator.bundle kss
cd kss
git checkout claude/keyboard-seller-simulator
```
Подключить свой GitHub потом можно так:
```
git remote set-url origin https://github.com/<вы>/<репозиторий>.git
git push -u origin claude/keyboard-seller-simulator
```

## 3. Откройте и запустите
1. Запустите Godot, нажмите **Import** и выберите файл `game/project.godot`.
2. Первое открытие займёт 1–2 минуты: Godot импортирует звуки и шрифты.
3. **F5** запускает игру.

Структура:
| Папка | Что внутри |
|---|---|
| `autoload/` | логика игры (game.gd), данные (data.gd), звук, онлайн-клиент, Steam |
| `scripts/` | 3D-клавиатура, меши, материалы, сборка (asm.gd) |
| `scripts/ui/` | интерфейс: тема, экраны, модальные окна |
| `scenes/` | главная сцена и 3D-мастерская |
| `data/catalog.json` | детали, раскладки, клиенты |
| `server/` | онлайн-сервер (Node.js) |
| `tests/` | автотесты (запуск сцены через F6) |

## 4. Соберите EXE
**Project → Export → Windows Desktop → Export Project**, сохраните как `KeyboardSellerSimulator.exe`.

Чтобы у EXE были своя иконка и версия, нужен **rcedit**:
1. Скачайте `rcedit-x64.exe`: https://github.com/electron/rcedit/releases
2. **Editor → Editor Settings → Export → Windows → rcedit** и укажите путь к файлу.

Без rcedit экспорт тоже работает, просто с иконкой Godot.

## 5. Онлайн-сервер локально
```
cd game/server
node server.mjs        # http://localhost:8787
node test.mjs          # автотест
```
В игре: **Настройки → Онлайн** → `http://localhost:8787` → «Подключиться».
Чтобы игроки подключались к вашему серверу, разверните его на VPS по `server/README.md`.

## 6. Steam
Пошаговая инструкция лежит в `ИНСТРУКЦИЯ_STEAM.md`: App ID, депо, достижения, GodotSteam.

## Полезно знать
- Сохранение игры хранится в `%APPDATA%\Godot\app_userdata\Keyboard Seller Simulator\save.json`. Удалите файл, чтобы начать с нуля.
- Игра начинается с двух сюжетных ремонтов (Дима и Лена), после них открывается сборка на заказ. Старые сохранения сразу получают доступ к сборке.
- Звуки собираются из записей скриптом `tools/build_snd.py`, источники перечислены в `CREDITS_ЗВУКИ.md`. Текстуры генерирует `tools/bake_tex.py`.
- Переменные окружения для отладки: `KSS_NOTITLE=1` пропускает титульный экран, `KSS_GFX=low` включает низкую графику.
